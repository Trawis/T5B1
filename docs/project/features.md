# Features

**F1** or the **Trainer** button opens Trainer Settings. F1 also brings an open
window to the front. **F2** closes it. The window reopens on the last tab used.

- **Actions**: one-shot buttons by domain. The *Product Name Here* box at the
  top of the Product section names the product for product actions.
- **Toggles**: settings saved with the game that act while on.
- **Settings**: Efficiency and Lead Efficiency (Default, 100%–8000%) and
  Discord.

Typed names must match exactly. Product actions search every company.
Company actions refuse a name shared by several companies. A target is taken
when the button is pressed. The change applies only if it still exists when
the dialog is answered.

⚠ marks a Yes/No confirmation that names the scope. No, Esc or closing
changes nothing.

### Switching toggles off

These toggles undo their changes: No Education Cost, Free Print, Full
Environment, Full Sun Light, Increase Walk Speed, Increase Courier Capacity,
Increase Print Speed, Reduce Internet Cost, Force Lights, Show Room Ceilings
and Unlimited Subsidiaries. The others stop but leave their changes:

| Toggle | What stays |
|---|---|
| Free Employees | Salaries and demands stay at 0 (saved) |
| Lock Age of Employees | Shifted birth dates (saved) |
| No Vacation | Postponed vacations; called-back employees stay |
| Full Satisfaction | Cleared negative thoughts |
| No Missed Support Tickets | Reset ticket ages |
| No Maintenance | Repairs (saved); raised chair comfort until reload |
| Increase Bookshelf Skill, Free Water & Electricity, Noise Reduction, Disable Furniture Stealing, Disable Fires | Furniture values until the save is reloaded |
| Auto toggles, Auto Accept Hosting Deals, More Hosting Deals | Promoted, started, finished, patented or accepted work, and added deals |
| Digital Distribution Monopol | Closed rival platforms |
| Disable Burglars, Disable Fire Inspection | Removed burglars and inspectors; inspection stays passed until the game changes it |
| Refund toggles | Money already refunded |
| Other toggles | Last values until the game writes them again |

## Toolbar buttons

These buttons act on the rows selected in the game's own lists. Anything else
selected only shows a message.

**Employees window.** Single-employee editors need exactly one selected
employee.

| Button | Effect |
|---|---|
| Trait | Toggles the employee's traits |
| Demand | Toggles a lead's design demands |
| LeadSpec | Sets lead specialization values per software type |
| Inspiration | Sets inspiration (0–2) |
| Founder ⚠ | Turns Founder on or off. A founder is unpaid and cannot be fired |
| Skills | For every selected employee: Set Skills (stars −3 to 3) and Set Base Skills (0–1, also raises the skill ceiling) |
| Make Happy ⚠ | Make All Employees Happy Now for the selected employees |

**Products window.** Exactly one of your software products (not an add-on,
framework, archived or foreign product).

| Button | Effect |
|---|---|
| Set Price / Set Stock / Set Active Users | As the Actions buttons, for that product |
| Fix Product Bugs | Removes every remaining bug of the released product |
| Max Awareness | Sets awareness to the category maximum once; it then fades normally |

**Companies window.** Exactly one AI company that is not yours, not your
subsidiary and not already going bankrupt.

| Button | Effect |
|---|---|
| Adjust AI Funds | As the action |
| Force Bankrupt ⚠ | As Bankrupt |
| Take Over | As Takeover Company |
| Make Subsidiary | As Subsidiary Company |
| Set Reputation | Sets the company's business reputation stars |

## Options screen

The game's Options screen has two trainer switches. Both are off by default
and stored in `DLLMods/<mod>Setting.txt`, not in saves.

- **Enable Experimental Features** shows the controls below. Turning it off
  switches the experimental toggles off.
- **Debug Logging** writes extra `Trainer [debug]:` lines to the dev console.

Retired settings (Reduce Box Price, Auto Max Market Share, More Creativity,
Reduce Expansion Cost, the old Experimental toggle) have no control. Values in
older saves are ignored.

Amazing Compatibility, Hire Employees, Fire Quietly and the skips are not
available in multiplayer.
