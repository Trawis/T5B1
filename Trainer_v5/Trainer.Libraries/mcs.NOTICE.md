# mcs.dll

`mcs.dll` is the C# compiler Software Inc bundles with the game, copied unmodified from the game's
`Managed` folder. Only `Trainer_v5.Tests` uses it, to run the Workshop source build through the game's
own compiler; it is not referenced by the mod project and is not packaged.
